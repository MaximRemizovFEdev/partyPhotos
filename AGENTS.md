# Правила работы в проекте

- Общайся на русском языке.

## Длина строк

- При создании и изменении кода соблюдай ограничение: не более 120 символов в строке, включая отступы.
- Переноси длинные выражения, списки аргументов, JSX и комментарии на несколько строк.
- Не разбивай неделимые значения (например, URL), если это изменит их смысл или поведение кода.

## Размер файлов и декомпозиция

- Основная область применения этого правила — фронтенд-код, особенно React-компоненты.
- Когда файл становится длиннее 250 строк, оцени возможность выделить самостоятельные части.
- Если файл превышает 300 строк, выполни декомпозицию перед завершением задачи.
- Выноси части по ответственности: компоненты интерфейса, хуки, утилиты и типы.
- Каждый выделенный модуль должен иметь понятное назначение. Не дели код механически ради числа строк.
- Сохраняй поведение кода при декомпозиции.
