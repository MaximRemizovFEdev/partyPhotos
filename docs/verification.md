# Проверка реализации

Дата: 27 октября 2026 года.

Выполнены production-сборка `npm run build`, проверка TypeScript `npm run check`
и интеграционный сценарий `npm test`. Автотест использует отдельный постоянный каталог и production-сервер.
Интерактивный браузер в среде недоступен. Мобильные устройства не подключались.

## Сопоставление с критериями приёмки

| № | Реализация и результат проверки |
| --- | --- |
| 1 | Главная страница использует один URL. Для печатного QR нужен итоговый HTTPS-домен; сканирование не проверено. |
| 2 | Камера и два поля реализованы. Доступ к физической камере и отправка из браузера не проверены. |
| 3 | После снимка выводится предпросмотр, пересъёмки нет. Проверено по коду, без интерактивного прогона. |
| 4 | Черновик существует только в React-состоянии. Обновление страницы не проверено в браузере. |
| 5 | Отправка требует фото, непустые имя и пожелание. Клиентская блокировка проверена по коду. |
| 6 | На клиенте стоят лимиты 300/50. API-тест подтверждает отсутствие серверного ограничения длины. |
| 7 | Запись localStorage выполняется после успешного ответа. Проверено по коду. |
| 8 | При загрузке читается отметка участия. Повторное открытие в браузере не проверено. |
| 9 | Автотест проверяет UUID-папку, два JPEG и info.json только с name/text, включая trim и переносы строк. |
| 10 | Запуск, повторный запуск во время отсчёта, неверные параметры и сброс проверены через API. |
| 11 | Сохранение фото после сброса проверено тестом. Код сброса не меняет localStorage. |
| 12 | Автотест подтверждает пустой список до открытия, включая состояние после сброса. |
| 13 | Истечение и отказ в отправке проверены API-тестом; автоматический переход UI проверен по коду. |
| 14 | Тест перезапускает сервер в collecting и gallery; время и записи сохраняются. |
| 15 | По коду сетка использует min и loading=lazy, Lightbox — full с preload=1. Сетевой график не проверен. |
| 16 | API проверено на 30 фото. Плавность прокрутки на телефоне не проверена. |
| 17 | Сетка связана с Lightbox, включены подписи и навигация. Интерактивный просмотр не проверен. |
| 18 | Safari на iPhone и Chrome на Android фактически не проверялись. |

По запросу пользователя пароль удалён, страница управления перенесена на `/odmen`.
Тест проверяет доступ без пароля и ответ 404 для старого `/admin`.

Дополнительно проверены лимит 5 МБ, отказ для недекодируемого файла,
исключение незавершённой записи, размеры 2000/400 px, отсутствие увеличения маленького исходника,
заголовки кеширования изображений и отсутствие кеширования списка.

Для быстрого теста истечения тестовая фикстура ставит в timer.json окончание через одну секунду.
Запуск через API отдельно проверяется с допустимыми часами и минутами; рабочие данные не меняются.

## Ручной прогон перед праздником

1. Разместить приложение на HTTPS и открыть `/odmen`.
2. Запустить минутный таймер. На iPhone и Android открыть главную страницу без отметки участия.
3. Разрешить камеру, проверить фронтальную и основную, сделать снимок и убедиться, что камера выключилась.
4. Проверить счётчики, пустые поля, переносы и блокировку отправки; обновить страницу до отправки.
5. Снова сделать снимок и отправить. Обновить страницу: должно остаться «Ваш кадр сохранён».
6. Дождаться окончания. Проверить автоматическое открытие галереи, подписи, просмотр и переключение фото.
7. Сбросить таймер: гости должны увидеть ожидание. Запустить снова: отметка участия и фотографии сохраняются.
8. Наполнить галерею минимум 30 фото, проверить плавность, ленивую загрузку и отсутствие массовой загрузки full.
9. Проверить отказ в доступе к камере, потерю сети, повторную отправку и повторную загрузку галереи.
10. Проверить QR-код с окончательным адресом на обоих устройствах.
